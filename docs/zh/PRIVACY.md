# 隐私政策

本译文仅为方便阅读。具有约束力的是[英文版本](../PRIVACY.md)。

版本 2 · 最后更新：2026年11月4日

本政策说明你使用 GameMate 时你的个人数据会发生什么。它的编写符合欧盟《通用数据保护条例》（GDPR）、德国《电信与数字服务数据保护法》（TDDDG）以及沙特阿拉伯王国《个人数据保护法》（PDPL）的要求。

## 2. 简要说明

- GameMate 在你的电脑上运行。**我们不接收、不收集也不存储你的任何数据。** 没有 GameMate 服务器、没有账户、没有广告、没有分析，也没有跟踪。
- GameMate 保存的一切都留在你的电脑上，位于你的 Windows 用户文件夹中。
- 只有当你使用需要其他公司服务的功能时，GameMate 才会连接这些服务。会把你的数据发送到别处的功能（Google Gemini、网页搜索、在线查询、查找你游戏的 Wiki）**在你开启之前都是关闭的**，你也可以随时关闭它们。
- **设置 → 隐私与法律** 中的 **删除我的数据** 会删除 GameMate 在你电脑上存储的所有内容。

## 3. GameMate 在你电脑上保存的内容

GameMate 将以下内容保存在你的 Windows 用户配置文件中它自己的文件夹里，只有你的 Windows 账户可以读取。保存这些内容是提供你所用功能所必需的（TDDDG 第 25 条第 2 款第 2 项）。

| 内容                                                                  | 原因                             | 保存多久                                         |
| --------------------------------------------------------------------- | -------------------------------- | ------------------------------------------------ |
| 你的设置，包括你何时接受这些文件以及何时给出每项同意                  | 记住你的选择，并作为你同意的记录 | 直到你更改设置或删除你的数据                     |
| 你的 Gemini API 密钥（如果你添加了），由 Windows 加密                 | 用于使用 Gemini                  | 直到你删除它、撤回对 Gemini 的同意或删除你的数据 |
| 你下载的 AI 模型、GameMate 的 AI 引擎、语音识别模型和语音             | 在你的电脑上运行 AI              | 直到你删除它们或删除你的数据                     |
| 找到或添加的游戏：名称、文件夹或程序、Wiki 地址                       | 帮助你玩正在玩的游戏             | 直到你撤回该同意或删除你的数据                   |
| GameMate 所做操作的日志（例如启动 AI 或检查更新），不含你的问题或回答 | 查找和修复问题                   | 约 1 MB，较旧的记录会被覆盖；随你的数据一起删除  |

你的对话、截图、语音录音以及伙伴注意到的内容 **只保存在内存中**，当你关闭聊天、关闭伙伴或退出 GameMate 时就会消失。截图和语音录音从不保存到磁盘。

## 4. GameMate 在你电脑上做什么

- **你的屏幕** 只会在以下情况下被截取：你发送带截图的问题、在开启截图时按下游戏内快捷键，或伙伴被设置为观察你的游戏期间。这由你在应用中选择；伙伴默认关闭。
- **你的麦克风** 只有在语音输入开启且你按下语音快捷键或 🎤 时才会使用。你的语音会在你的电脑上转换为文字。
- 在你电脑上运行的 **AI 模型**（GameMate 自己的引擎，或你使用的 Ollama）只在你的电脑上接收你的问题和截图。

## 5. 需要你同意的可选功能

这些功能在你开启之前都是关闭的。开启某项功能即表示你同意此处所述内容（GDPR 第 6 条第 1 款 (a) 项、TDDDG 第 25 条第 1 款、PDPL）。你可以随时通过关闭该功能撤回每项同意；这会停止该功能，但不影响之前已进行的处理。

### 查找你的游戏（设置 → 游戏）

GameMate 会读取你电脑上 Steam、Epic Games、Battle.net 和 Riot 的游戏列表、你的 CurseForge 整合包文件夹以及前台程序的名称。这些都留在你的电脑上。为了找到每款游戏的 Wiki，**只有游戏名称** 会被发送到 wiki.gg 和 Fandom。撤回这项同意也会删除 GameMate 找到的游戏列表。

### 在线查询（设置 → AI 与在线）

当问题涉及游戏中的某个内容时，GameMate 会把 **主题**（例如“Ender Dragon”）发送到该游戏的 Wiki（例如 minecraft.wiki、某个 Fandom Wiki 或 wiki.gg Wiki），对于 Minecraft 模组还会把模组名称发送到 Modrinth，并下载它向你展示的页面文字和图片。你的问题本身不会被发送。

### 网页搜索（设置 → AI 与在线）

仅在 Gemini 开启时可用。对于有关当前情况（版本强势玩法、补丁、赛季）或玩家推荐的问题，且 Wiki 中没有答案时，GameMate 或 AI 会根据你问题中的关键词和游戏名称生成一个简短的 **搜索查询**（例如“Overwatch characters currently meta”），GameMate 只会通过 Gemini API、使用你的 API 密钥把该查询发送给 Google。你的对话、截图和其他问题不会一并发送。Google 会搜索网页（包括 Reddit 等论坛），返回摘要、所用页面和它的搜索建议，GameMate 会把这些与回答一起显示。Google 根据 Gemini API 的条款及其隐私权政策处理该查询（见下文 Google Gemini）。搜索会计入你的 API 密钥的 Google Search 免费额度；如果你的密钥开启了计费，Google 可能会对超出额度的搜索收费。

### Google Gemini（设置 → AI 与在线）

如果你选择用 Gemini 回答问题或用于伙伴，GameMate 会向 Google 发送：你的问题、到目前为止的对话、你附加的或伙伴截取的截图、伙伴最近注意到的内容，以及你的 API 密钥。Google 作为独立的控制者，依据 [Gemini API Additional Terms of Service](https://ai.google.dev/gemini-api/terms) 和 [Google 隐私权政策](https://policies.google.com/privacy) 处理这些数据。视你的 Google 账户而定，Google 可能会使用这些数据改进其服务。Google 要求你年满 18 周岁。

## 6. 不属于可选同意的连接

- **你启动的下载**（从 Hugging Face 下载的 AI 模型、语音识别模型和自然语音，从 GitHub 下载的 GameMate AI 引擎）会在你点击 **下载** 时连接这些服务，因为这是你要求的（GDPR 第 6 条第 1 款 (b) 项）。
- **检查更新** 会在 GameMate 启动后不久以及每隔几个小时向 GitHub 询问 GameMate 的最新版本，如有新版本则下载。我们这样做是为了提供安全修复和改进（我们的正当利益，GDPR 第 6 条第 1 款 (f) 项）。你可以在 **设置 → 常规** 中关闭此功能。在你接受使用条款之前，GameMate 不会检查更新。

与互联网上的任何连接一样，这些请求会向服务方显示你的 IP 地址和基本技术信息（例如应用名称和版本）。我们从不接收这些信息。

## 7. 谁会收到数据

只有你通过 GameMate 使用的服务，各自作为独立的控制者，依据各自的隐私政策处理：Google（Gemini）、你查询的游戏 Wiki（例如 Fandom、wiki.gg、minecraft.wiki）、Modrinth、Hugging Face 和 GitHub（隶属于 Microsoft）。我们不会出售你的数据，也不会与任何人分享，因为我们从未拥有它们。

## 8. 向其他国家传输

其中一些服务位于美国或欧盟和沙特阿拉伯以外的其他国家，或在那里处理数据。只有当你使用连接它们的功能时，数据才会到达这些服务。对于从欧盟传出的数据，这些公司依赖 GDPR 规定的保障措施，例如 EU-US Data Privacy Framework 或标准合同条款。如果你居住在沙特阿拉伯，使用这些功能意味着你的数据会应你的要求被传输到王国境外。

## 9. 你的权利

根据 GDPR，你有权访问你的数据（第 15 条）、更正数据（第 16 条）、删除数据（第 17 条）、限制处理（第 18 条）、以可携带的格式获取数据（第 20 条）、反对基于正当利益的处理（第 21 条），以及随时撤回任何同意（第 7 条第 3 款）。根据 PDPL，你有权获得告知、访问你的数据并获取副本、要求更正、补全或更新数据、要求销毁数据，以及撤回你的同意。

由于 GameMate 存储的一切都在你自己的电脑上，你可以直接在 GameMate 中行使大部分权利：在设置中查看和更改你的选择、关闭可选功能，以及使用 **删除我的数据**。对于 Google、各 Wiki、Hugging Face 或 GitHub 持有的数据，请联系这些服务。其他任何事项，请发邮件至 [TSCKey1@outlook.com](mailto:TSCKey1@outlook.com)。

## 10. 投诉

你可以向数据保护机构投诉，特别是你居住或工作所在地的机构：

- **在欧盟：** 你所在国家的数据保护机构（[欧盟机构列表](https://www.edpb.europa.eu/about-edpb/about-edpb/members_en)）。在德国，是你所在联邦州的数据保护机构。
- **在沙特阿拉伯：** 负责监管 PDPL 的 Saudi Data & AI Authority（SDAIA）（[sdaia.gov.sa](https://sdaia.gov.sa)）。

## 11. 儿童

GameMate 面向 16 周岁及以上的人，或经父母或法定监护人许可的更年轻者。按照 Google 的要求，Gemini 仅供 18 周岁及以上的人使用。

## 12. 没有自动化决策

GameMate 不会对你作出具有法律效力或类似重大影响的决定。AI 只负责回答你的问题。

## 13. 本政策的变更

如果我们更改本政策，新版本会随 GameMate 更新一起提供，GameMate 会在你继续使用前向你显示。你随时可以在 **设置 → 隐私与法律** 中阅读现行版本。
