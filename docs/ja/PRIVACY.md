## 2. 要点

- GameMate はあなたの PC で動きます。**私たちはあなたのデータを一切受け取らず、収集も保存もしません。** GameMate のサーバー、アカウント、広告、分析、トラッキングはありません。
- GameMate が保存するものはすべて、あなたの PC の Windows ユーザーフォルダーに残ります。
- GameMate は、他社のサービスが必要な機能を使うときにだけ、そのサービスに接続します。あなたのデータを外部に送る機能（Google Gemini、ウェブ検索、オンラインでの調べもの、ゲームの Wiki の検索）は **オンにするまでオフ** で、いつでもオフに戻せます。利用規約に同意した後に GameMate が表示する画面で、または後から **設定** でオンにできます。
- **設定 → プライバシーと法的情報** の **データを削除** で、GameMate が PC に保存したものをすべて削除できます。

## 3. GameMate が PC に保存するもの

GameMate は次のものを、あなたの Windows ユーザープロファイル内の専用フォルダーに保存します。このフォルダーはあなたの Windows アカウントからしか読めません。保存は、あなたが使う機能を提供するために必要です（TDDDG 第 25 条第 2 項第 2 号）。

| 内容                                                                                | 目的                                           | 保存期間                                                      |
| ----------------------------------------------------------------------------------- | ---------------------------------------------- | ------------------------------------------------------------- |
| 設定（これらの文書に同意した日時や、各同意を行った日時を含む）                      | 選択内容を覚えておくため、また同意の記録として | 変更するか、データを削除するまで                              |
| Gemini の API キー（追加した場合。Windows により暗号化）                            | Gemini を使うため                              | 削除するか、Gemini への同意を取り消すか、データを削除するまで |
| ダウンロードした AI モデル、GameMate の AI エンジン、音声認識モデル、音声           | PC で AI を動かすため                          | 削除するか、データを削除するまで                              |
| 見つかった、または追加したゲーム：名前、フォルダーまたはプログラム、Wiki のアドレス | プレイ中のゲームを手助けするため               | その同意を取り消すか、データを削除するまで                    |
| GameMate が行ったことのログ（AI の起動や更新の確認など。質問や回答は含みません）    | 問題を見つけて直すため                         | 約 1 MB。古い記録は上書きされ、データ削除時に消去             |

会話、スクリーンショット、音声の録音、コンパニオンが気づいたことは **メモリ上にのみ保持** され、チャットを閉じる、コンパニオンをオフにする、または GameMate を終了すると消えます。スクリーンショットと音声の録音がディスクに保存されることはありません。

## 4. GameMate が PC で行うこと

- **画面** は、スクリーンショット付きで質問を送ったとき、スクリーンショットがオンの状態でゲーム内ショートカットを押したとき、またはコンパニオンがゲームを見守るよう設定されている間にだけキャプチャされます。これはアプリで選べます。コンパニオンは初期状態でオフです。
- **マイク** は、音声入力がオンで、音声ショートカットまたは 🎤 を押したときにだけ使われます。あなたの話した言葉は PC 上で文字に変換されます。
- PC で動く **AI モデル**（GameMate 独自のエンジン、または使っている場合は Ollama）は、あなたの質問とスクリーンショットを PC 上でのみ受け取ります。

## 5. 同意が必要なオプション機能

これらの機能は、オンにするまでオフです。オンにすることは、ここに書かれた内容への同意となります（GDPR 第 6 条第 1 項(a)、TDDDG 第 25 条第 1 項、PDPL）。各同意は、機能をオフにすることでいつでも取り消せます。取り消すと機能は止まりますが、それ以前に行われたことには影響しません。利用規約に同意した後に GameMate が表示する画面でもオンにできます。

### ゲームを見つける（設定 → ゲーム）

GameMate は、PC 上の Steam、Epic Games、Battle.net、Riot のゲーム一覧、CurseForge のモッドパックのフォルダー、前面にあるプログラムの名前を読み取ります。これらは PC 内にとどまります。各ゲームの Wiki を見つけるために、wiki.gg と Fandom には **ゲームの名前だけ** が送られます。この同意を取り消すと、GameMate が見つけたゲームの一覧も削除されます。

### オンラインでの調べもの（設定 → AI とオンライン）

質問がゲーム内の何かについてのとき、GameMate はその **トピック**（たとえば「Ender Dragon」）をそのゲームの Wiki（minecraft.wiki、Fandom の Wiki、wiki.gg の Wiki など）に送り、Minecraft の Mod の場合は Mod の名前を Modrinth に送って、表示するページの本文と画像をダウンロードします。質問そのものは送られません。

### ウェブ検索（設定 → AI とオンライン）

Gemini がオンのときだけ使えます。今の流行（メタ、パッチ、シーズン）やプレイヤーのおすすめについての質問で、Wiki に答えがない場合、GameMate または AI は質問のキーワードとゲーム名から短い **検索クエリ**（たとえば「Overwatch characters currently meta」）を作り、GameMate はそのクエリだけを、あなたの API キーを使って Gemini API 経由で Google に送ります。会話、スクリーンショット、ほかの質問は一緒に送られません。Google はウェブ（Reddit などのフォーラムを含む）を検索し、要約、使ったページ、検索候補を返し、GameMate はそれらを回答とともに表示します。Google はこのクエリを Gemini API の規約と同社のプライバシー ポリシーに従って処理します（下の Google Gemini を参照）。検索は API キーの Google Search 無料枠に含まれます。キーで課金が有効になっている場合、無料枠を超える検索には Google が料金を請求することがあります。

### Google Gemini（設定 → AI とオンライン）

回答やコンパニオンに Gemini を選ぶと、GameMate は次のものを Google に送ります：あなたの質問、それまでの会話、添付したスクリーンショットやコンパニオンが撮ったスクリーンショット、コンパニオンが最近気づいたこと、そしてあなたの API キー。Google はこれらを、独立した管理者として [Gemini API Additional Terms of Service](https://ai.google.dev/gemini-api/terms) と [Google プライバシー ポリシー](https://policies.google.com/privacy) に従って処理します。Google アカウントの設定によっては、Google がこのデータをサービスの改善に使うことがあります。Google は 18 歳以上であることを求めています。

## 6. オプションの同意ではない接続

- **あなたが始めたダウンロード**（Hugging Face からの AI モデル、音声認識モデル、ナチュラル音声、GitHub からの GameMate の AI エンジン）は、あなたが求めたものなので、**ダウンロード** をクリックしたときにそれらのサービスに接続します（GDPR 第 6 条第 1 項(b)）。その画面でダウンロードにチェックを入れて **続ける** をクリックしても、ダウンロードが始まります。
- **更新の確認** では、GameMate の起動直後と数時間ごとに GitHub に最新バージョンを問い合わせ、新しいバージョンがあればダウンロードします。セキュリティ修正や改善を届けるために行っています（私たちの正当な利益、GDPR 第 6 条第 1 項(f)）。**設定 → 一般** でオフにできます。利用規約に同意する前に、GameMate が更新を確認することはありません。

インターネット上のあらゆる接続と同じく、これらの通信ではサービス側にあなたの IP アドレスと基本的な技術情報（アプリの名前やバージョンなど）が伝わります。私たちがこの情報を受け取ることはありません。

## 7. データを受け取る者

あなたが GameMate を通じて使うサービスだけで、それぞれが独立した管理者として独自のプライバシーポリシーに従います：Google（Gemini）、調べもの先のゲームの Wiki（Fandom、wiki.gg、minecraft.wiki など）、Modrinth、Hugging Face、GitHub（Microsoft の傘下）。私たちはあなたのデータを持つことがないため、誰かに販売したり共有したりすることもありません。

## 8. 他国への移転

これらのサービスの一部は、米国その他の EU 外・サウジアラビア外の国に拠点を置くか、そこでデータを処理しています。データがそれらに届くのは、接続する機能をあなたが使ったときだけです。EU からの移転については、これらの企業は EU-US Data Privacy Framework や標準契約条項など、GDPR に基づく保護措置に依拠しています。サウジアラビアに住んでいる場合、これらの機能を使うことは、あなたの求めに応じてデータが王国外へ移転されることを意味します。

## 9. あなたの権利

GDPR に基づき、あなたにはデータへのアクセス権（第 15 条）、訂正権（第 16 条）、削除権（第 17 条）、処理の制限権（第 18 条）、ポータブルな形式で受け取る権利（第 20 条）、正当な利益に基づく処理への異議申立権（第 21 条）、およびいつでも同意を取り消す権利（第 7 条第 3 項）があります。PDPL に基づき、あなたには通知を受ける権利、データにアクセスしその写しを得る権利、データの訂正・補完・更新を求める権利、データの破棄を求める権利、および同意を取り消す権利があります。

GameMate が保存するものはすべてあなた自身の PC にあるため、これらの権利のほとんどは GameMate の中で直接行使できます。設定で選択内容を確認・変更し、オプション機能をオフにし、**データを削除** を使ってください。Google、各 Wiki、Hugging Face、GitHub が保有するデータについては、それぞれのサービスに問い合わせてください。その他のことは [TSCKey1@outlook.com](mailto:TSCKey1@outlook.com) までメールでご連絡ください。
