# Security policy

## Supported versions

Security fixes go into the latest release of GameMate. GameMate updates itself, so please make sure you are on the [latest release](https://github.com/TSCKey/gamemate/releases/latest) before reporting.

| Version        | Supported |
| -------------- | --------- |
| Latest release | Yes       |
| Older releases | No        |

## Reporting a vulnerability

Please **don't open a public issue** for a security problem. Report it privately:

1. On GitHub: **Security → Report a vulnerability** ([open a private report](https://github.com/TSCKey/gamemate/security/advisories/new)), or
2. by email to [TSCKey1@outlook.com](mailto:TSCKey1@outlook.com).

Please include what you found, how to reproduce it, and which GameMate version and Windows version you used. Never include a real Gemini API key.

You'll get a reply within 7 days. Once the problem is confirmed, the fix ships in the next release, and you'll be credited in the release notes unless you'd rather not be.

## What counts

For example:

- the Gemini API key leaving the PC other than to Google, or being readable by other Windows users;
- a web page, wiki or download making GameMate run code or open files or programs;
- GameMate's built-in AI engine being reachable from other devices or other programs;
- downloads (AI models, voices, the AI engine, updates) being accepted without matching their checksums;
- GameMate going online or reading the PC before the player accepted the Terms of Use or turned the feature on.

Wrong or unhelpful AI answers are not security problems; please report them as a normal issue.
